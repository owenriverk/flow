River flows by text, from anywhere

LateBoof is a free river-gauge bot for whitewater paddlers. Text a run name to 866-284-5181 from a Garmin inReach or any phone — or send it to flow@lateboof.com from an inReach — and one message comes back with the live reading. No app, no account, and on satellite, no cell signal at all.

The idea: you should be able to check the river from the put-in, not from the last place with a bar of signal.

It only knows the runs below. The list is hand-curated — a few dozen rivers, each pointed at the gauge paddlers actually quote for that section. Text a name exactly as it appears under “Text this,” or a raw USGS or WSC gauge ID. Anything else comes back “not found.”
